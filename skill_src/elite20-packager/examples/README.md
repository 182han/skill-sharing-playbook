# examples/ — 真实运行记录

> 本目录里的数字**全部来自真实终端输出**，不是手写的示例。
> 复现方式：`bash examples/run_demo.sh <PACKAGE_DIR>`

---

## 复现命令

```bash
# 自动挑一个 ~/Desktop 下的提交包
bash examples/run_demo.sh

# 或指定包
bash examples/run_demo.sh ~/Desktop/张三_C5_提交包
```

没有真实包时，脚本会自动降级为演示两种**不需要真实包**的场景（空包报缺 / `--scaffold` 生成骨架）。

3. **跑完 scaffold 后再检查，仍然报缺失** —— 从机制上堵死"骨架冒充成品"。

## 运行 5：对不存在的路径（错误处理）

```bash
$ python3 scripts/elite20_packager.py /tmp/不存在的目录
[错误] 路径不存在：/tmp/不存在的目录
```

**退出码**：`2`（用法/路径错误，与"有缺失项"的 `1` 区分开）

---

## 退出码约定

| 退出码 | 含义 | 会不会被 `set -e` 拦下 |
|---|---|---|
| `0` | 无缺失项 | 否 |
| `1` | 有缺失项（**这是正常的检查结果**） | 是 |
| `2` | 用法错误 / 路径不存在 | 是 |

> 写脚本调用它时注意：`1` 不代表「工具坏了」，只代表「这个包缺东西」。
