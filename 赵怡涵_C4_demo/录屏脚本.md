# 录屏脚本 · elite20-packager

> **状态：【待赵怡涵执行】。本文件是分镜脚本，视频尚未录制。**
> 目标时长 2–3 分钟。按下面的顺序敲命令即可，不需要任何剪辑技巧。

---

## 录制前准备

```bash
# 1) 清掉之前的演示残留，保证画面干净
rm -rf /tmp/演示_空包_C4_提交包 /tmp/演示输出

# 2) 打开一个干净的终端窗口，字号调大到 16pt 以上（录制用）
# 3) 终端宽度至少 100 列（报告表格会换行）
cd ~/Desktop/赵怡涵_C4_提交包
```

**录制工具建议**：macOS 自带 `QuickTime Player` → 文件 → 新建屏幕录制；或 `Cmd+Shift+5`。

---

## 分镜

### 镜头 1（0:00–0:15）— 说清这个技能是什么

**画面**：终端停在包目录，`ls` 一下。

```bash
ls -la
```

**旁白**：
> 这是 Elite20 提交包自检器。给它一个提交包文件夹，它告诉你缺什么文件、怎么补。
> 全班每个人做每个挑战都要交同一套证据账本，缺文件是最高频的扣分原因——
> 而这个工具把它变成一条命令。

---

### 镜头 2（0:15–0:45）— 核心用法：对一个真实包跑自检

**敲**：

```bash
python3 skill_src/elite20-packager/scripts/elite20_packager.py "$(pwd)" --challenge C4
```

**旁白**：
> 这是我自己这个 C4 包。三层检查——六件套、仓库结构、挑战专属交付物——
> 加三条红线自检。跑完直接告诉我还缺什么。

**停顿 3 秒**，让观众看清输出。

---

### 镜头 3（0:45–1:15）— **重点**：证明它真的会报缺

**旁白**：
> 但是一个"永远说 OK"的检查器是没用的。所以看这个——

**敲**：

```bash
mkdir -p /tmp/演示_空包_C4_提交包
python3 skill_src/elite20-packager/scripts/elite20_packager.py /tmp/演示_空包_C4_提交包 --challenge C4 --no-xlsx -o /tmp/演示输出
echo "退出码: $?"
```

**旁白**：
> 空包报 28 项缺失，退出码 1。这样才说明它真的在检查。

---

### 镜头 4（1:15–1:45）— `--scaffold` 一键起包

**敲**：

```bash
python3 skill_src/elite20-packager/scripts/elite20_packager.py /tmp/演示_空包_C4_提交包 \
    --challenge C4 --student 演示 --scaffold --no-xlsx -o /tmp/演示输出
find /tmp/演示_空包_C4_提交包 -type f | sort
head -12 /tmp/演示_空包_C4_提交包/演示_C4_AI日志.md
```

**旁白**：
> 一键生成 23 个骨架。注意——**骨架里只有「待填」占位，没有一句假内容**。
> 这是刻意的：骨架是用来填的，不是用来交的。

---

### 镜头 5（1:45–2:15）— 打开报告

```bash
open reports/packager_report.md
# 滚到"三、逐项修复建议"
```
